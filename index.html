Selected systems at UBS

Two of the platforms I work on in UBS Wealth Management, and a live model of the scale-out design.

KafkaSpring BootWebSocket tierLive clients

Real-time notifications

Events stream in from Kafka, are persisted, and are pushed live to users in the browser over authenticated WebSockets, using short-lived JWTs verified against JWKS. I'm working on the redesign that lets the WebSocket tier scale out: instances keep no per-user session state and broadcast each event, so any instance can serve any connection.

  • Kafka
  • Spring Boot
  • WebSockets
  • JWT · JWKS
Kafka · AvroSpring BatchPostgreSQLValue generators

Lending value processing

Consumer services read Avro messages from Kafka and load pipe-delimited files through Spring Batch into PostgreSQL, feeding generator services that calculate lending values. I'm working on redesigning it for performance.

  • Kafka
  • Avro
  • Spring Batch
  • PostgreSQL

Scale-out, live

Every instance receives every event and pushes it to whoever is connected to it. Take an instance down: its clients reconnect elsewhere and every client still gets every event.

A sample event is published every few seconds. Try the buttons.
